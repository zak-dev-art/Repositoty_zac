Farm Fresh

A modern web platform for moving services in Kenya, enabling seamless booking and management of relocation logistics.

The Problem

Moving services in Kenya lacked a unified digital platform where users could easily compare options, get instant quotes, and manage their relocations. Most services were unorganized, lacked transparency, and required phone calls or in-person visits to complete bookings.

My Solution

I developed a full-stack web application that serves as a bridge between users and moving service providers. The platform enables users to browse available moving services, get real-time quotes, book services, and track their relocation progress—all from their browser.

The solution features a responsive design optimized for mobile users (the primary use case in Kenya), integrated payment processing, and a comprehensive admin dashboard for service providers to manage bookings and customer interactions.

Tech Stack Used

React
Tailwind CSS
FastAPI
PostgreSQL
Vercel

Key Features Delivered

  • User registration and authentication with email verification
  • Service provider directory with real-time availability
  • Intelligent quote system based on distance and service type
  • Secure payment integration for online transactions
  • Order tracking and status updates with push notifications
  • Rating and review system for service quality assurance

Challenges & Learnings

Challenge 1: Real-time Data Sync — Managing real-time quote updates and availability across multiple providers required careful optimization to prevent excessive database queries.

Solution: Implemented caching strategies and optimized API endpoints to reduce latency.

Challenge 2: Mobile-First Design — Designing a platform that works seamlessly on lower-end Android devices with limited bandwidth was challenging but essential for the Kenyan market.

Solution: Focused on progressive enhancement, optimized image sizes, and implemented service workers for offline functionality.

Key Learning: Understanding your user base's constraints and designing for them first leads to more robust and widely accessible applications.
